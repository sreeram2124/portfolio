# M Sreeram Reddy — Portfolio

Personal portfolio inspired by Sadhana's macOS-style portfolio, customized with Sreeram's projects, skills, experience, contact information, and meeting links.

**Live site:** https://sreeram2124.github.io/portfolio/

## Features

- Responsive macOS-style portfolio with animated role titles and app-like project, skills, experience, calendar, and contact views
- Working window controls, dock navigation, and persistent appearance, wallpaper, and text-size settings
- Light and dark themes with smooth transitions
- Contact links for email, LinkedIn, GitHub, X, Cal.com, and Calendly
- Cal.com meeting scheduler and portfolio chat interface

## Run locally

Open `index.html` in a browser or serve the folder with any static web server. No build step is required.
